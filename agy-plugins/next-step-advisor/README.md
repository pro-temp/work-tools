# 下一步建议（Next-Step Advisor）

为 Antigravity 提供类似 Codex 风格的上下文下一步建议，采用 **A + B 组合模式**：

1. **常驻轻量建议（方案 A）**：每轮完成实质性任务（改代码、修 Bug、排查分析、写方案）后，在回复末尾自动附带最多 3 条（通常 2–3 条）贴合上下文的中文下一步建议；回复 `1` / `2` / `3`、`1和2` 或 `1，顺便...` 回车即可直接执行，不阻塞当前回合。
2. **按需点击卡片（方案 B）**：随时输入 `/next`，结合当前会话进度与工作区变更（如 `git status`），弹出 Antigravity 原生可点击选项卡片，点一下直接执行。

## 模型说明

无论是常驻建议还是 `/next` 卡片，均由**当前会话选定的同一个主模型**生成，不切换模型，完整共享上下文。

## 开关方式

在 Antigravity 的 Customizations / 插件页面中可一键启用或禁用本插件；禁用后常驻规则与 `/next` 命令会同步关闭，不影响其他插件。
