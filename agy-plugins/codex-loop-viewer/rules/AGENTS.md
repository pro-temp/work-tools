# Codex Loop 侧栏视图联动提示

当通过 `codex-loop` 向 Codex 派单时：

- 聊天中必须继续按 `codex-loop` 约定发送可点击的 `[codex://threads/<id>](codex://threads/<id>)` 桌面直达链接。
- 若本插件的侧栏 Sidecar（`codex-loop-viewer/viewer`）已启用且正在运行，可在首轮启动消息中额外附带一枚 `[Codex Loop](sidecar://codex-loop-viewer/viewer/)` 胶囊，方便用户在 Antigravity 右侧辅助栏原样查看实时交互。
