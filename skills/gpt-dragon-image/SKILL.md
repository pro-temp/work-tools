# GPT 白龙娘生图

## 接到绘图请求

- “画个 GPT 龙娘头像”“把她换成水彩风”都可以直接画。未指定数量时，单一场景出一张。用户给了多个场景或总张数，就按要求分配。
- 用户说想挑方向时，再给方案。按用户要求的数量列出，未指定时给五个情境或动作明显有别的方向。每项写清她在做什么、是什么表情、镜头能看到什么。用户选好后按选中的数量开画，默认每个方向一张。只要点子或提示词的请求，以文字交付。
- 默认画成日系 Q 版、穿白紫礼裙，输出无字 PNG。用户指定的画风、头身比、衣着、姿势、背景、透明度、文字和画幅分别生效。系列图沿用已经选定的设计，只变动每张的主题或用户点名的部分。

## 用图认准同一个角色

以下路径均从本技能目录解析，换项目也能取到同一份素材。

| 素材 | 何时使用 | 从中取什么 |
| --- | --- | --- |
| [原设立绘](assets/standing.png) | 全身、换装、动作、侧背面或场景插画 | 角的形状、发色、礼裙结构、背后的小翼和粗鳞尾，是角色外形的主参考 |
| [头像参考](assets/avatar.png) | 头像、表情特写、延续这版脸型 | 眼型、鬓边银饰和头肩构图。歪头浅笑与暮紫背景可以随题目更换 |
| [完整角色设定](references/character-setting.md) | 涉及她的来历、绘画委托、额度耗尽、同伴关系或指定台词 | 查对应段落，把性格落在动作上。用户要原句时核对说话人和字词 |

用本地角色图作为重绘输入。先查看本次选用的图片，再把图片实际附给内置 ImageGen，并说明每张图的用途。改用户已有的图时，以用户原图为编辑底图，角色图补充外形。用户给的姿势、服装或画风参考，只影响指定的部分。原设资料已随包保存，日常绘图可直接取用。

## 构图和逐张验收

1. 头像默认用 1:1 头肩近景。让双眼在小图里仍然清楚，角尖和盘结发饰都落进方图的内切圆。全身立绘则给角、翼和尾尖留出空间。近景、闭眼或背面时，只核对构图里应当能看见的特征。
2. 每一张都打开实际成图，对照参考检查可见的龙角、头发、眼睛、发饰、翼尾，再看用户指定的动作、服装、物件、文字与背景。用户主动更改的特征，以本次要求为准。多人图还要检查每套特征属于正确的角色，例如鲸鱼娘用蓝色鳍尾，白龙娘用银角和鳞尾。
3. 有 Python 和 Pillow 时，可用 [inspect_image.py](scripts/inspect_image.py) 读取实际格式、宽高和透明度范围。头像应再看一次居中的圆形小图，可用下列命令生成临时预览并打开查看。透明背景还要目视主体外缘，确认空白处确实透明。角色特征始终需要看图核对。

   ```text
   python "<技能目录>/scripts/inspect_image.py" "<成图>" --circle-preview "<任务临时目录>/<图名>-circle.png"
   ```

4. 发现具体缺陷就定向修正并复查，例如把镜头拉远，让两只角进入圆内。每张达标即停止，遵守用户给出的生成次数或预算。把合格原图存到用户指定的位置，未指定时放当前任务的输出目录。圆形检查图留在临时目录。
